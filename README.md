## Sobre El Proyecto

Este repositorio contiene mi portfolio personal: una experiencia web estatica, performante y visualmente expresiva, construida con HTML, CSS y JavaScript vanilla.

El sitio no funciona como una simple landing page. Esta pensado como una pieza interactiva para mostrar criterio tecnico, sensibilidad visual y proyectos que simulan problemas reales de negocio.

## Highlights

- Experiencia responsive-first para desktop, tablet y mobile.
- Carrusel 3D de proyectos con drag, controles, teclado y dots.
- Animaciones fluidas con GSAP, ScrollTrigger y Lenis.
- Secciones para perfil, skills, APIs, proyectos, experiencia, herramientas y contacto.
- Demos independientes dentro de `projects/`, cada una con su propio HTML, CSS y JS.
- Sin framework ni build step: se puede abrir directamente en el navegador.

## Ejecutarlo Localmente

Como es un sitio estatico, alcanza con abrir `index.html` en el navegador.

Tambien podes levantar un servidor local:

```bash
npx serve .
```

o con Python:

```bash
python -m http.server 8000
```

Luego abri:

```text
http://localhost:8000
```
